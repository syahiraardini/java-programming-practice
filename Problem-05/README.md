# Problem 05 - Simple Number Analyzer

## Objective
Use the following array:
- int[] numbers = {12,-5,0,7,-3,8,0,15,-10,4};

The program must determine:
- How many numbers are positive
- How many numbers are negative
- How many numbers are zero
- The total of all numbers
- The maximum number
- The minimum number

  Don't use Arrays.sort(), Math.max() or Math.min() to solve the problem.

## Concepts Practice
This problem summarizes the previous 4 concepts into one problem to test my understanding so far.

## My Approach
I implement the same techniques as I used in the previous problems, while being more careful when setting the initial value for the maximum and minimum numbers.
