# Problem 01 — Integer Checker

## Objective
Write a Java program that asks the user to enter an integer.
The program must determine whether the number is:
- positive
- negative
- or zero

# Concepts Practiced
- Variables
- if-else
- Scanner class

## My Approach
I first create a Scanner object, then I create a variable to store the user's input. The input is used as the condition in an if control structure.
- If the input is greater than 0, the program prints "Positive".
- If the input is less than 0, the program prints "Negative".
- If the input is neither greater than nor less than 0, the program prints "Zero".

## What I Learned
If I have to check three conditions, I only need to define conditions for the first two. If neither of those conditions is true, the else statement handles the third condition.
